Amazon Sales Performance Dashboard

Project Overview

This project uses Microsoft Power BI to analyze Amazon sales data and understand business performance.

Tools Used

- Microsoft Power BI
- Data Analysis
- Data Visualization

Project Objectives

- Analyze sales trends.
- Explore product performance.
- Understand key business metrics.
- Present insights through visualizations.

Project File

- "amazon dashboard.pbix" — Power BI dashboard file.

How to Open

1. Download the ".pbix" file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard and its visualizations.
